# AI 模拟面试规格

阶段 3 开始前必读。定义场景还原、导师分工、状态机、输出结构、语音链路、总结机制与异常处理。所有模型能力都通过适配层，不得在视图层直接调模型。

## 1. 场景还原的依据

面试页不得做成"一个光球 + 一句提问"。真实复试是**多位导师围坐、现场独立评分、全程记录**的场景，产品必须还原这一点。

可核验依据（写入产品说明时必须带出处）：

| 事实 | 出处 |
| --- | --- |
| 面试小组一般不少于 5 人，成员现场独立评分，全程录音录像 | 教育部《2026 年全国硕士研究生招生工作管理规定》第五十二条，moe.gov.cn/srcsite/A15/moe_778/s3261/202509/t20250918_1413836.html |
| 每生面试时间一般不少于 20 分钟；复试小组一般不少于 5 人；须现场记录 | 教育部办公厅《关于加强硕士研究生招生复试工作的指导意见》，hudong.moe.gov.cn/srcsite/A15/moe_778/s3113/200603/t20060303_79971.html |
| 面试含外语听说、专业素质与能力、综合素养三部分，不少于 5 名复试教师，20 分钟 | 首都经济贸易大学财政税务学院 2025 年复试细则（PDF，yjs.cueb.edu.cn） |
| 外语听说面试时间不少于 5 分钟；面试不少于 20 分钟 | 上海海关学院 2025 年税务硕士复试细则（PDF，yjsc.shcc.edu.cn） |
| 税务专硕综合面试常拆为综合素质 40 + 专业能力 40 + 外语听说 20（各校权重不同） | 吉林大学经济学院税务专硕复试细则（第三方转载，需以学院官网为准） |

**规则**：各校权重、时长、环节顺序差异很大，产品**不得把某一校的权重写成通用标准**。默认用"通用结构 + 可配置权重"，并在界面标注"训练量表，非院校官方评分"。

## 2. 导师组构成（5 人 + 1 秘书）

| 角色 | 定位 | 主要提问 | 对应评分维度 |
| --- | --- | --- | --- |
| 组长（主问） | 教授，专业方向负责人 | 开场、控场、核心专业题、追问节奏 | 逻辑结构 |
| 专业导师 A | 税收理论方向 | 税制原理、税收学基础、概念辨析 | 内容完整性、专业表达 |
| 专业导师 B | 税务实务与政策方向 | 涉税案例、政策热点、税收筹划 | 内容完整性、专业表达 |
| 外语导师 | 财税英语 | 英文自我介绍、英文专业问答（≥5 分钟） | 语言组织 |
| 综合导师 | 思政与综合素质 | 学习经历、职业规划、人文素养、报考动机 | 综合素养与表达得体 |
| 秘书（可选） | 记录与计时，不提问 | 无 | 不参与评分 |

设计约束：
- 导师是**虚构角色**，界面必须标注"AI 模拟角色，非真实导师"。禁止使用真人照片、真人姓名、真实院校在职教师身份。
- 每个角色有固定的人格参数（语速、追问强度、打断倾向），可配置，不可在运行时随机漂移。
- 追问必须由角色归属决定：专业题追问只由 A/B/组长发起；外语环节只有外语导师提问；综合环节由综合导师与组长交替。
- 压力模式提高 B 的追问频率与组长的打断倾向，但**不得模拟侮辱、贬低、人格攻击**。
- 导师的非语言反馈（点头、记录、皱眉、翻材料）只用于氛围，不生成文字评价，且可在设置里关闭。

## 3. 场景与呈现

场景要素（RealityKit 场景或等价实现）：

```
会议室（8–12 ㎡）
├─ 长桌（考生与导师隔桌相对）
├─ 导师席：5 座位，弧形或一字排开，组长居中
├─ 考生席：单椅，正对导师席（第一人称视角，不出现自己形象）
├─ 背景：白墙 + 投影幕 / 书架 / 校徽位（校徽位默认留空，不虚构学校）
├─ 桌面道具：评分表、笔、水杯、考生材料
└─ 光线：顶部均匀白光，无戏剧化打光
```

呈现分层（必须实现，按设备与设置自动选择）：

| 级别 | 表现 | 适用 |
| --- | --- | --- |
| L1 标准 | 3D 场景 + 5 个半身像模型（LOD）+ 微动作 | 高配设备，默认 |
| L2 中配 | 3D 场景 + 2D 立绘导师（billboard，2–3 帧表情切换） | 中配 / 帧率不足 |
| L3 轻量 | 预渲染静态背景图 + 当前提问导师高亮头像条 | 低配 / 减少动态效果 / 低电量 |

交互要求：
- 相机基本固定（模拟考生坐姿），只允许小幅左右转头（±15°），不做自由漫游，避免变成"逛场景"。
- 当前发言导师高亮（描边或灯光），其余导师降低饱和度。
- 发言时有口型或至少音量驱动的下颌动画；无口型能力时用"呼吸 + 轻微点头"替代，不得静止不动。
- 字幕常驻（可关），显示当前问题全文。
- 顶部保留"模拟中"状态与模式名，右上角保留"不露脸 / 仅语音"隐私开关。

## 4. 状态机

单一 `InterviewSession` 状态机，状态转移必须由事件驱动，禁止在视图里散落 if。

```
idle
 → preparing        选参数（专业/题型/难度/时长/输入方式/导师风格）
 → connecting       建立模型连接 + 场景资源加载
 → greeting         组长开场与自我介绍引导
 → asking           某位导师出题
 → listening        录音中（语音模式）
 → transcribing     流式识别中
 → reviewing        转写完成，用户可编辑确认
 → evaluating       评分与生成反馈
 → followingUp      追问中（可回 asking / 继续追问）
 → switching        切换提问导师（外语环节、综合环节）
 → paused           暂停（计时冻结，场景保留，允许恢复）
 → finishing        收尾，生成总结
 → feedback         结果页
 → archived         落库完成
失败旁路：any → error(kind) → 可恢复回到上一稳定态，或 → abandoned
```

规则：
- `error` 必须带 `kind`：`network`、`timeout`、`asrFailed`、`modelFailed`、`quotaExceeded`、`permissionDenied`、`sceneLoadFailed`。
- 每种 `kind` 对应唯一恢复动作，恢复失败则降级，不许原地无限重试。
- `sceneLoadFailed` 不得阻断面试：降级到 L3 静态背景继续，或纯音频 + 字幕模式。
- 用户主动退出在作答中走 `abandoned`，保留已作答内容并标记"未完成"，不算一次有效训练。
- 暂停超过配置上限（默认 24 小时）自动归档为 `abandoned`。

## 5. 准备阶段参数

| 参数 | 取值 | 影响 |
| --- | --- | --- |
| 专业 | 税务专硕（默认）等经管类专业 | 决定题库与知识库检索范围 |
| 题型 | 专业面试 / 综合面试 / 学习经历追问 | 决定导师分工与 prompt 模板 |
| 难度 | 基础 / 进阶 / 压力 | 决定追问深度、打断频率、思考时间 |
| 时长 | 10 / 15 / 20 分钟（默认 20） | 决定题量；20 分钟对应"一般不少于 20 分钟" |
| 模式 | 全真模拟 / 专项练习 | 全真按"外语 → 专业 → 综合"顺序，专项只练一类 |
| 导师风格 | 温和 / 标准 / 严格 | 只调追问强度与节奏，不调评分标准 |
| 输入 | 文字 / 语音 | 语音不可用时自动落文字 |

默认流程顺序（全真模式）：
`组长开场（1 分钟）→ 外语导师英文环节（5 分钟）→ 专业导师 A/B 抽题与追问（8–10 分钟）→ 综合导师提问（3–5 分钟）→ 组长收尾（1 分钟）`

## 6. 结构化输出

模型必须返回可校验结构，解析失败按 `modelFailed` 处理，不得把半截文本渲染成评分。

```json
{
  "turnId": "string",
  "speaker": "lead|major_a|major_b|foreign|comprehensive",
  "question": { "text": "string", "type": "professional|general|experience", "knowledgePoints": ["string"] },
  "followUp": { "shouldAsk": true, "reason": "string", "question": "string" },
  "evaluation": {
    "completeness": { "score": 0, "evidence": "引用原文片段", "comment": "string" },
    "logic": { "score": 0, "evidence": "string", "comment": "string" },
    "professionalExpression": { "score": 0, "evidence": "string", "comment": "string" },
    "languageOrganization": { "score": 0, "evidence": "string", "comment": "string" },
    "improvements": [{ "issue": "string", "example": "string", "note": "示例非唯一答案" }]
  },
  "citations": [{ "sourceId": "string", "title": "string", "snippet": "string" }],
  "confidence": "high|medium|low",
  "uncertainty": "string|null"
}
```

约束：
- `score` 区间与含义在代码里定义为常量并单元测试，量表说明必须展示给用户。
- `evidence` 必须是对用户回答的真实引用片段，不能是模型自造引文。校验：`evidence` 需为该轮 transcript 的子串或高度重叠，否则丢弃该维度并用 `uncertainty` 说明。
- `citations` 为空时 `confidence` 不得为 `high`。
- 不输出录取概率、不输出"院校会给你打几分"、不输出"导师一定会喜欢"。
- **不评价文本之外的东西**：禁止"眼神躲闪""不够自信""坐姿不佳"这类无依据判断。视频模式也只能基于语音停顿、语速、重复词等可测信号，并注明是信号推断。

## 7. 反馈页规则

1. 五维展示：内容完整性、逻辑结构、专业表达、语言组织、改进建议。改进建议不强行打分为主指标。
2. 每个维度可展开看引用片段，片段高亮对应原文。
3. 按导师归属展示评价（"专业导师 B 追问了 3 次"），让用户理解压力来源，而不是笼统打分。
4. 改进示例显式标注"示例表达，不是唯一标准答案"。
5. 固定展示训练量表说明与免责声明。
6. 薄弱点生成推荐：优先匹配已审核题库，其次匹配课程章节，都不匹配时给出"暂无对应练习"而不是硬凑。
7. 多次对比只比较同题型、同难度的记录，跨类型对比必须提示不可直接比。

## 8. 语音链路

```
麦克风权限 → 录音（AVAudioEngine）→ 流式分片 → ASR 适配层 → 增量文本 → 用户编辑 → 确认提交
```

要求：
- 权限拒绝：直接切文字模式，给出一次说明，不反复弹窗。
- 流式识别中断：保留已识别部分，提供"继续识别 / 手动补充 / 重录"。
- 识别质量差（置信度低于阈值或长度异常）：提示用户核对，不静默提交。
- 转写文本必须可编辑，编辑后以编辑版作为评分输入。
- 录音文件默认不持久化，仅内存持有，会话结束释放。需要保留时必须是用户显式开启且单独授权。
- 日志只记时长、字数、错误码；不记原文、不记音频、不记问题内容。

## 9. 知识依据

- 检索来源：已审核的院校公开信息、课程讲义、题库解析、专业教材摘要，全部带 `sourceId` 与 `reviewStatus`。
- 只检索 `reviewStatus = approved` 的内容。未审核内容不进检索池。
- 检索不到时：明确说明"该问题缺少可核验依据，以下为通用训练建议"，并把 `confidence` 降到 `low`。
- 禁止编造：院校复试细则、导师研究偏好、往年真题原文、录取比例。用户问到这类内容且库中无依据时，回答"未收录可核验信息"，并建议去招生单位官网核对。

## 10. 面试总结与点拨

### 10.1 触发方式

**自动触发**（任一满足即进入 `finishing` 并生成总结）：

- 全部计划题目与追问完成；
- 计时到达设定时长（到点后允许答完当前题，不再出新题）；
- 用户点击"结束面试"；
- 连续 2 轮无有效作答（空文本、识别为空、明确跳过全部）；
- 异常中断后用户选择"结束并查看总结"。

**手动触发**：

- 面试过程中任意时刻可点"生成阶段总结"（不结束会话）：产出截至目前的小结，之后仍可继续。
- 结果页可重新生成一次（换模型或参数），旧版本保留可对比，不得覆盖。

触发必须幂等：同一 `sessionId` 重复触发只返回首次结果，不重复计次、不重复扣额度。

### 10.2 总结结构

```json
{
  "sessionId": "string",
  "headline": "一句话结论（不含录取判断）",
  "overall": {
    "dimensions": [{ "key": "completeness", "score": 0, "trend": "up|flat|down", "basis": "string" }],
    "vsHistory": { "comparable": true, "sameType": "professional", "delta": 0, "note": "string" }
  },
  "perQuestion": [{
    "question": "string",
    "speaker": "major_b",
    "answered": true,
    "yourPoints": ["你实际说到的要点"],
    "missingPoints": ["该题常考但你没提到的要点"],
    "evidence": "原文片段",
    "followUpExposed": "追问暴露的问题"
  }],
  "topActions": [
    { "action": "具体可执行动作", "why": "为什么", "howToCheck": "怎么自检已改到位" }
  ],
  "examples": [{ "issue": "string", "rewrite": "改进示例", "note": "示例非唯一答案" }],
  "recommendations": [{ "type": "question|course", "id": "string", "reason": "string" }],
  "uncertainty": ["低置信或缺少依据的项"],
  "disclaimer": "训练量表，非院校官方评分；不预测录取结果"
}
```

### 10.3 "准确点拨"的硬约束

"准确"指**可追溯**，不是指话说得漂亮：

1. 每条评价必须能指到 `transcript` 的具体片段，指不到就删掉。
2. 区分三类表述并在界面用不同标记：
   - **事实**：你说了什么（直接引用）；
   - **判断**：逻辑跳跃、论据不足、概念混淆（说明依据在哪个片段）；
   - **建议**：可改成什么样（标注为建议，不是标准答案）。
3. `topActions` 恰好 3 条，且必须是可执行动作（"下次回答税收筹划题时，先用一句话给定义，再给一个企业场景，最后给风险提示"），不是"加强练习""提升逻辑"这类空话。
4. `missingPoints` 必须来自已审核题库/讲义，无依据时留空并写入 `uncertainty`。
5. 不比较"你和上岸者的差距"，不给百分比通过率，不给院校内部评分口径。
6. 低置信项单列，不混进结论。
7. 总结页必须给出"本次覆盖了哪些知识点、没覆盖哪些"，让用户知道样本边界。

### 10.4 与成长/推荐的联动

- 总结归档后触发一次成长事件（`interviewCompleted`），只计一次。
- `recommendations` 跳转必须落到具体题号或课程章节；落不到就不显示该条。
- 薄弱知识点写入用户画像，供题库与首页任务使用，写入规则见 `architecture-data.md` 的单一数据源约定。

## 11. 异常与降级矩阵

| 异常 | 检测 | 处理 | 用户可见 |
| --- | --- | --- | --- |
| 模型超时 | 超过配置阈值 | 重试 1 次 → 降级为轻量模板反馈 | 提示本次反馈为简化版 |
| 模型限流/额度 | 429 / quota | 排队或提示稍后 | 明确剩余额度 |
| 结构化解析失败 | JSON 校验不过 | 重试 1 次 → 标记该轮无评分 | 不显示假分数 |
| ASR 失败 | 连续失败 | 切文字模式 | 一次性说明 |
| 场景加载失败 | 资源缺失/超时 | 降 L3 静态背景，继续面试 | 提示已切换轻量场景 |
| 网络中断 | 请求失败 | 缓存本轮，恢复后续传 | 顶部断网条 |
| 用户杀进程 | 启动检测未归档会话 | 恢复为"未完成"，提供继续/放弃 | 恢复提示 |
| 重复提交 | 幂等键命中 | 返回首次结果 | 无重复计分 |
| 总结生成失败 | 解析或超时 | 保留原始记录，提供"重新生成" | 明确未生成成功 |

## 12. 模型适配层

```swift
protocol InterviewModelProviding {
    func nextQuestion(_ ctx: InterviewContext) async throws -> QuestionTurn
    func evaluate(_ turn: AnswerTurn) async throws -> Evaluation
    func summarize(_ session: InterviewSession) async throws -> SessionSummary
}
```

- 实现：`MockInterviewModel`（样板默认）、`RemoteInterviewModel`（正式接入）。
- 两者异常语义一致，都抛同一 `InterviewError` 枚举。
- 请求层统一记录 `durationMs`、`tokenUsage`、`errorKind`、`modelId`，写本地指标表，不上报正文。
- 提示词与评分量表放配置文件，改量表不重新编译视图层。
- 密钥从 `Secrets` 读取（环境变量 / 本地 plist 且已 gitignore），禁止硬编码。
