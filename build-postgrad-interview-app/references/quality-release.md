# 测试与上线质量规格

阶段 7 与交付前必读。核心原则：**只记录真实执行结果**。没跑过就写"未执行"，跑了失败就写失败与实际报错。

## 1. 测试分层

| 层 | 范围 | 工具 | 门禁 |
| --- | --- | --- | --- |
| 单元 | 领域规则、成长计算、权益判断、解析与校验 | XCTest / Swift Testing | 覆盖关键分支，边界值必测 |
| 集成 | 仓储 + 同步队列 + mock 服务异常 | XCTest | 幂等、冲突、重试 |
| UI | 五条核心流程、四态页面、3D 认领与社区交互 | XCUITest | 流程可完整走通 |
| 手动 | 3D 渲染、手势、后台、发热、视觉验收 | 真机 | 有记录、有结论 |
| 性能 | 首帧、帧率、内存、包体、耗电 | Instruments | 实测值 + 是否达标 |

## 2. 单元测试必测项

- 成长值：每个事件类型、每日上限、连续奖励、跨日边界、幂等重复同一事件。
- 等级曲线：每一级边界（0、刚好达成、超出 1 点、满级封顶）。
- 权益判断：未订阅 / 有效 / 已过期 / 恢复购买 / 降级后锁定内容。
- 正确率与薄弱点：样本不足、全对、全错、跨知识点聚合。
- 面试状态机：全部合法转移 + 非法转移被拒绝 + 每种 error 的恢复路径。
- 结构化输出校验：缺字段、分数越界、`evidence` 不在原文中时被丢弃。
- 同步：重复幂等键、冲突取新、重试退避上限。
- 数据删除：注销后本地表、缓存、Keychain、队列全清。

## 3. UI 测试必测项

| 编号 | 场景 | 断言 |
| --- | --- | --- |
| U1 | 注册 → 档案 → 计划 | 首页出现今日任务 |
| U2 | 完成课程 → 结果页 | 进度写入、成长值增加、宠物反馈出现 |
| U3 | 刷题 → 提交 → 解析 | 记录落库、错题本可查 |
| U4 | 面试文字模式全流程 | 反馈页五维齐全、引用片段非空 |
| U5 | 面试语音失败降级 | 自动切文字且不丢已输入内容 |
| U6 | 认领形象 → 保存 → 重进 | 配置持久化 |
| U7 | 进社区 → 互动 → 退出 | 场景可进可退，热点可点 |
| U8 | 非会员访问会员内容 | 锁定态出现，解锁入口可跳转 |
| U9 | 模拟购买 → 权益生效 → 模拟过期 | 内容解锁/回锁正确 |
| U10 | 断网下打开有缓存的课程 | 可读 + 顶部离线提示 |
| U11 | 注销账号 | 二次确认 + 回游客态 + 数据清空 |
| U12 | 减少动态效果开启后进场景 | 循环动画停止，功能仍可用 |

## 4. 异常矩阵

每个异常至少一条可复现用例，且断言"用户看到什么"而不只是"没崩溃"。

| 类别 | 用例 | 期望 |
| --- | --- | --- |
| 网络 | 断网、弱网、切飞行模式中途恢复 | 明确提示 + 可恢复 + 不丢已输入 |
| 超时 | 模型、内容、同步各自超时 | 有重试上限，超限给结论 |
| 重复提交 | 连点提交、断网重发 | 幂等，只记一次 |
| 识别失败 | ASR 返回低置信 / 中断 | 保留已识别，可编辑，可重录 |
| 模型异常 | 429、5xx、结构解析失败 | 降级或标记无评分，不显示假分数 |
| 3D | 资源丢失、下载失败、哈希不匹配 | 用旧版本或占位 + 重试，入口不消失 |
| 3D | 内存警告、切后台、低电量 | 释放缓存/降级/恢复，功能不丢 |
| 支付 | 取消、失败、恢复无项、过期 | 状态正确，不误判成功 |
| 同步 | 冲突、乱序、重复事件 | 取新、去重、可查待同步 |
| 隐私 | 撤回通知/语音/推荐授权 | 相关能力立即停用且不报错 |
| 账号 | 注销中退出 App 再进入 | 状态一致，冷却期可撤销 |

## 5. 设备与系统覆盖

样板阶段至少覆盖：

- 屏幕：小屏（SE 级别）、主流（6.1"/6.3"）、大屏（Pro Max 级别）。
- 系统：最低支持版本 + 最新正式版。
- 设备档位：高（支持完整 3D）、中、低（验证轻量模式）。
- 语言与区域：简体中文（主），至少验证一次换行与数字格式。

无法覆盖的组合必须在交付说明写"未覆盖"，不得默认"应该没问题"。

## 6. 性能检查

提出可测量建议值（**未经项目确认前标为待确认**），实测后分开记录：

| 指标 | 建议目标（待确认） | 测量方式 |
| --- | --- | --- |
| 3D 场景帧率 | 高配 ≥50fps，中配 ≥30fps | Instruments / Metal 计数器 |
| 场景首帧时间 | 高配 ≤2.5s，中配 ≤4s | 打点计时 |
| 场景切换 | ≤1.5s | 打点计时 |
| 内存峰值（3D 页） | 高配 ≤350MB，中配 ≤250MB | Instruments Allocations |
| 冷启动 | ≤1.8s | Instruments App Launch |
| 包体增量（3D 资产） | 按资源预算，超出必须走按需下载 | Xcode Build Report |
| 连续使用 10 分钟发热 | 无"严重"温升提示 | 真机体感 + 温度记录 |
| 帧率稳定性 | 无持续掉帧（>20% 帧超过 33ms） | Instruments |

**禁止声明已达成具体数值，除非有本次实测记录。** 交付时给"目标值 / 实测值 / 设备型号 / 结论"四列。

## 7. 隐私与安全

- 权限申请文案说明用途，且只在需要时申请（不要在启动时批量弹）。
- 语音：默认不保存原始音频；保存必须单独授权且有明确删除入口。
- 日志：不含密钥、令牌、原文转写、昵称、院校、手机号。发布前搜一遍日志语句。
- 仓库：`.gitignore` 覆盖 `Secrets.*`、`*.xcuserstate`、构建产物；提交前检查无凭据。
- 用户协议与隐私政策：可达、非死链、有更新日期。
- 数据导出与删除：提供入口，删除范围可读。
- 内容安全：UGC（昵称、打卡文案、社区发言）有审核态与举报路径。
- 未成年人/敏感场景提示：教育产品按实际合规要求处理，不确定时标注待法务确认。

## 8. 上线验收表

交付前逐项勾，任一未过不得称"可上线"：

- [ ] 构建无错误无警告（或警告已登记原因）
- [ ] 单元测试全绿，失败项为 0
- [ ] UI 测试 U1–U12 全绿
- [ ] 五条核心流程真机各走一遍
- [ ] 3D 场景真机渲染、交互、后台恢复、内存警告各验证一次
- [ ] 轻量模式在小屏/低配可用，功能无缺失
- [ ] 支付为 mock 或沙箱，交付说明写明未做真实交易
- [ ] 所有列表页五态可见（含无权限）
- [ ] 注销与授权撤回路径可用
- [ ] 性能四列表已填，未达项有原因与后续计划
- [ ] 隐私与仓库卫生检查通过
- [ ] 交付说明的"未验证项"完整、具体、可复现

## 9. 命令清单（macOS 环境）

```bash
# 构建
xcodebuild -scheme <Scheme> -destination 'platform=iOS Simulator,name=iPhone 16' build

# 单元 + UI 测试
xcodebuild test -scheme <Scheme> -destination 'platform=iOS Simulator,name=iPhone 16'

# 真机
xcrun devicectl list devices
xcodebuild -scheme <Scheme> -destination 'id=<UDID>' build

# 包体
xcodebuild -scheme <Scheme> archive -archivePath build/App.xcarchive
```

非 macOS 环境：以上命令**不可执行**，交付说明必须写"构建与测试未执行，缺 Xcode 环境"，并附此清单供在 macOS 上复跑。不得用"代码看起来正确"替代。
