# 设计系统规格

第 2 步与新增组件时读。目标：普通页面与 3D 场景是同一个产品，不是两个拼在一起的模块。

## 1. 视觉原则

1. **沉静优先。** 备考场景以低刺激为底色，强调色只用于行动与状态，不用于装饰。
2. **一屏一主行动。** 每个页面只有一个主按钮级别，其余降为次级或文字链。
3. **进度可见。** 任何"要持续做的事"（课程、计划、成长）都必须有可读进度。
4. **2D 与 3D 同源。** 同一色板、同一字体层级、同一圆角与阴影逻辑；3D 场景的 HUD 是同一套组件的延伸。
5. **可访问不是附加项。** 动态字体、对比度、触控区、减少动态效果在组件层就满足，不做事后补丁。

## 2. 颜色

用语义命名，不用颜色名。每个语义色给浅色/深色两套值。

| Token | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `bg/base` | 页面底色 | #F7F8FA | #101114 |
| `bg/raised` | 卡片 | #FFFFFF | #1A1C21 |
| `bg/sunken` | 分组底 | #EFF1F5 | #0B0C0F |
| `text/primary` | 主文字 | #16181D | #F2F3F5 |
| `text/secondary` | 副文字 | #5A606B | #A8ADB7 |
| `text/tertiary` | 弱提示 | #8C929C | #6E747F |
| `brand/primary` | 主行动 | #2F6BFF | #6E9BFF |
| `brand/subtle` | 品牌浅底 | #E8EFFF | #16233D |
| `state/success` | 完成 | #1E9E6A | #3FC98C |
| `state/warning` | 提醒 | #C77700 | #F0A83C |
| `state/danger` | 错误/删除 | #D93B3B | #FF6B6B |
| `state/locked` | 会员锁定 | #B98A00 | #E0B34A |
| `border/subtle` | 分隔 | #E3E6EB | #262A31 |

规则：
- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1。
- 状态色不得单独承载语义，必须配图标或文案（色盲可用）。
- 3D 场景的环境光与雾色从 `bg/base` 派生，避免场景与页面割裂。

## 3. 字体与排版

用系统字体（SF Pro），支持动态字体。

| 层级 | 字号/字重 | 用途 |
| --- | --- | --- |
| `display` | 32 / Bold | 结果页大数字 |
| `title1` | 24 / Semibold | 页面标题 |
| `title2` | 20 / Semibold | 卡片标题 |
| `headline` | 17 / Semibold | 列表主文本 |
| `body` | 16 / Regular | 正文 |
| `callout` | 15 / Regular | 次要正文 |
| `footnote` | 13 / Regular | 辅助说明 |
| `caption` | 12 / Regular | 标签、时间 |

规则：
- 行高 = 字号 × 1.45（正文），标题 × 1.25。
- 中文标题不使用全大写英文式处理；数字用等宽数字（`.monospacedDigit()`）避免跳动。
- 长文本（资料、解析）最大行宽不超过屏幕宽的 92%，左右至少 16pt 内边距。

## 4. 间距、圆角、阴影

- 间距刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。页面水平边距 16，卡片内边距 16，列表行高 ≥ 56。
- 圆角：小 8（标签）、中 12（输入框）、大 16（卡片）、超大 24（弹层与 3D HUD 面板）。
- 阴影：仅卡片与浮层使用，`y=2 blur=8 opacity=0.06`（浅色）/ 深色用 1px 描边替代阴影。
- 触控区最小 44×44pt，图标视觉尺寸可小于 44，热区不可小于 44。

## 5. 组件清单

每个组件必须定义：默认 / 按下 / 禁用 / 加载 / 错误 五态，以及动态字体与深色模式表现。

| 组件 | 必需状态 | 说明 |
| --- | --- | --- |
| `PrimaryButton` | 默认/按下/禁用/加载 | 加载中保留原宽度，不跳变 |
| `SecondaryButton` | 同上 | 描边样式 |
| `TextLinkButton` | 默认/按下/禁用 | 次要操作 |
| `Card` | 默认/可点击/禁用 | 统一圆角与内边距 |
| `ListRow` | 默认/选中/禁用 | 左图标+主副文本+右辅助 |
| `FilterChip` | 未选/已选/禁用 | 题库筛选用 |
| `ProgressBar` | 确定/不确定/分段 | 课程与计划 |
| `RingProgress` | 单环/双环 | 每日目标 |
| `StateView` | loading/empty/error/offline/noPermission | **统一四态加权限态，禁止各页自造** |
| `Toast` / `InlineBanner` | info/success/warning/error | 断网用常驻 banner，不用 toast |
| `Sheet` / `FullScreenCover` | 半屏/全屏 | 3D 场景用全屏 |
| `AvatarBadge` | 5 种形象状态 | 2D 列表与 3D 场景共用同一状态枚举 |
| `LockedOverlay` | 会员锁定/未登录锁定 | 必须含"为什么锁 + 解锁方式" |
| `StatTile` | 有数据/数据不足 | 统计卡 |
| `TimelineItem` | 正常/进行中/已完成 | 面试历史、成长明细 |
| `SceneHUD` | 正常/加载/失败/轻量模式 | 3D 场景浮层容器 |

`StateView` 是强制组件：任何列表、详情、场景都必须能渲染这五态，写测试时逐态截图或断言。

## 6. 2D 与 3D 衔接

1. **进入**：点击 3D 入口 → 全屏过渡（0.35s 淡入 + 轻微缩放），加载进度显示在 HUD 中央，不用白屏。
2. **退出**：左上角固定返回按钮（含图标与"返回"文案），下滑手势仅作辅助。
3. **HUD 与页面同构**：HUD 面板使用同一 `Card` 圆角（24）与同一字体层级，按钮复用 `PrimaryButton`。
4. **色彩连续**：场景环境色、地面色从 `bg/base` 与 `brand/subtle` 派生；避免出现与 App 无关的高饱和场景。
5. **数据同源**：HUD 显示的成长值、任务数与 2D 页面读同一数据源，不单独计算。
6. **降级连续**：轻量模式下场景退化为静态背景 + 热点按钮列表，视觉仍是同一套色与字体，不能变成"另一个 App"。

## 7. 可访问性

| 项 | 要求 |
| --- | --- |
| 动态字体 | 支持到 AX5，不截断，长文本用多行；列表行高自适应 |
| VoiceOver | 每个可交互元素有 label；装饰性 3D 元素 `accessibilityHidden`；3D 场景提供"场景内容列表"替代路径，可读可点 |
| 对比度 | 正文 4.5:1，非文本 UI 3:1 |
| 触控 | ≥44×44pt，相邻热区间距 ≥8pt |
| 减少动态效果 | 关闭循环动画、相机自动旋转、页面转场降为淡入 |
| 字幕 | 音频类内容提供文字稿 |
| 语音 | 语音输入必须可切文字，不强制麦克风 |
| 焦点顺序 | 3D 场景内的焦点按 HUD → 热点列表 → 退出 排列 |

## 8. 交互状态规范

- **加载**：≤300ms 不显示 loading（避免闪烁）；>300ms 显示骨架屏；>2s 加进度或分步文案。
- **空**：说明为什么空 + 一个可执行动作（去刷题 / 去选课），禁止只写"暂无数据"。
- **失败**：一句人话说明 + 重试按钮 + 可选"查看详情"（错误码折叠）。
- **离线**：顶部常驻 banner + 缓存内容可用 + 明确哪些操作需要联网。
- **无权限**：说明缺哪个权限 + 去设置按钮 + 该页面其余内容仍可见。
- **锁定**：内容预览模糊或截断 + 权益说明 + 去会员页。
- **危险操作**（注销、删除记录）：二次确认 + 明确列出会被删除的范围 + 主按钮不用红色以外的强调色混淆。

## 9. 动效规范

- 时长：微交互 120–180ms，转场 250–350ms，结果类 400–600ms。
- 曲线：进入 `easeOut`，退出 `easeIn`，强调用轻微 spring（阻尼 ≥0.8，避免弹跳过度）。
- 禁止：装饰性无限循环动画占主视觉、动画阻塞交互、动画中不可点击。
- 所有动效都要在"减少动态效果"下有一个静态等价物。
