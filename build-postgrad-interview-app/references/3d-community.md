# 3D 形象、电子宠物与学习社区规格

阶段 4、5 开始前必读。3D 是核心模块，不允许推迟或降级为静态展示。

## 1. 技术选型

**默认方案：SwiftUI + RealityKit + Reality Composer Pro。**

理由（评估其他引擎时必须给出同等颗粒度的对照）：
- 与 SwiftUI 共用一套视图与状态，2D 页面与 3D 场景之间的数据传递不需要跨引擎桥接。
- 内建 ARKit 集成、材质系统、动画混合、空间音频，减少自研成本。
- 无第三方运行时，包体增量主要是资产本身，不额外背一个渲染引擎。
- 缺点需承认：复杂后处理与大量自定义着色器不如 Unity 灵活；跨平台不可复用。

若改选 Unity / Godot 等：必须写清集成方式（原生插件或嵌入渲染视图）、包体增量估算、维护成本、与 SwiftUI 状态同步方案、性能实测数据。未实测不得写"性能更好"。

## 2. 场景结构

| 场景 | 用途 | 必备元素 |
| --- | --- | --- |
| 社区大厅 | 社交与氛围，冷启动第一屏 | 中心广场、其他用户形象代理、公告牌热点、进入个人空间入口 |
| 个人学习空间 | 个人成长可视化 | 自己的形象、电子宠物、书桌/白板等学习设施、装扮展示位、成长进度装置 |
| 小组共同学习空间 | 共同学习与监督 | 多名成员形象、共享白板、共同计时装置、成员状态标识 |

每个场景必须包含：入口（从哪个 Tab 进入）、返回路径（显式关闭按钮）、Loading 过渡（不用白屏直接切）、失败态（资源加载失败可返回并重试）。

场景目录规范：

```
Resources/Scenes/<scene-id>/
  scene.usdz              场景根
  assets/                 场景专属模型
  materials/              材质与贴图
  audio/                  环境音与音效
  hotspots.json           热点定义
  meta.json               { "sceneId", "version", "minAppVersion", "assetHash" }
```

## 3. 资源与格式规范

| 类型 | 格式 | 约束 |
| --- | --- | --- |
| 三维模型 | USDZ（交付）/ USD（源文件） | 单模型面数上限按设备档位分档，见下表 |
| 动画 | USDZ 内嵌骨骼动画 或 RealityKit 动画剪辑 | 命名统一 `<avatarId>_<state>_<variant>` |
| 材质 | Physically Based，贴图 2 的幂 | 单张 ≤ 2048×2048，优先 1024 |
| 音频 | m4a / caf | 音效 ≤ 200KB，环境音 ≤ 2MB，可流式 |
| 图标与 UI 图 | Asset Catalog | 提供 1x/2x/3x 或单张矢量 |

面数分档（样板建议值，**未经真机实测前标注为待确认**）：

| 档位 | 形象 | 宠物 | 场景总面数 |
| --- | --- | --- | --- |
| 高性能（A15 及以上） | ≤ 30k tris | ≤ 15k tris | ≤ 300k tris |
| 中性能 | ≤ 15k tris | ≤ 8k tris | ≤ 150k tris |
| 轻量模式 | 静态图或 ≤ 5k tris | ≤ 3k tris | ≤ 60k tris |

每个资产目录必须带 `meta.json` 记录版本与哈希，用于缓存失效判断。资产升级不覆盖旧版本，新版本用新目录，避免线上旧包找不到资源。

## 4. 形象认领流程

```
浏览（网格列表预览）→ 3D 预览（旋转/缩放/自动旋转）→ 选择 → 命名 → 确认认领 → 首次引导 → 进入个人空间
```

规则：
- 预览页支持单指旋转、双指缩放、双击复位；同时提供"自动旋转"与"复位"按钮，手势不是唯一操作方式。
- 未认领状态：成长、社区入口显示引导卡，不显示空白。
- 重新选择：允许更换形象，已获得的装扮与成长值保留；更换有确认弹窗说明"装扮将按新形象重新映射"。
- 认领后写 `AvatarProfile`（含 `avatarId`、`displayName`、`slots`、`unlockedItems`、`claimedAt`），并触发一次同步。

## 5. 个性化与槽位

槽位固定：`hair`、`outfit`、`accessory`、`colorTheme`、`petSkin`。

| 状态 | 表现 | 可操作性 |
| --- | --- | --- |
| 已拥有 | 正常显示 | 可装备/卸下 |
| 未解锁 | 灰显 + 解锁条件 | 点击展示条件，不弹购买 |
| 会员专属 | 带权益标识 | 非会员点击引导会员页 |
| 预览中 | 场景内临时应用 | 可取消，取消后回滚到已保存配置 |

保存策略：本地立即写入（保证离线可用），再异步推服务端；冲突以 `updatedAt` 较新者为准，冲突记录进同步日志。

### 学位帽与流苏（硕士毕业帽）

形象与电子宠物共用同一套学位帽资产，槽位为 `headwear = mortarboard`，流苏颜色单独存 `tasselColor`，便于会员配色与学科主题切换。

结构拆分（`Assets/Headwear/mortarboard/`）：

| 部件 | 命名 | 规格 |
| --- | --- | --- |
| 方形帽板 | `cap_board` | 边长按头围缩放，厚度 ≤0.02 单位，四角微圆 |
| 帽箍 | `cap_band` | 贴合头部曲线，留发型穿插余量（避免穿模） |
| 帽扣 | `cap_button` | 中心小圆扣，流苏挂点 |
| 流苏 | `tassel` | 3–5 段骨骼链 + 条带贴图（alpha 镂空），禁止用高面数丝线建模 |

流苏动画：
- **待机微摆**：骨骼链做低频摆动（约 1.2Hz），单节摆幅 ≤5°，重力方向固定，不随相机晃动。
- **拨穗**：从右前侧拨至左前侧，时长 0.8s，带轻微回弹；方向以学校仪式规范为准，产品不做"标准方向"宣传。
- **庆祝**：升级或毕业成就时整体轻微上扬后回落，2s 内结束。
- **减少动态效果**：流苏固定为静态下垂，不播放拨穗，改为静态姿态切换。

性能与材质：
- 面数预算：帽板 ≤800 tris，帽箍 ≤300，流苏 ≤600（轻量模式直接用静态贴图替换整套）。
- 材质：帽板哑光织物（roughness ≥0.8，无金属反射）；流苏用双面透明贴图，关闭阴影投射以省开销。
- 佩戴时不额外增加光源，沿用场景光照；不使用实时布料或物理模拟。

解锁与权益：
- 首次完成一次模拟面试即解锁基础黑色学位帽（与"复试"主题呼应），写入 `unlockedItems`。
- 流苏配色属装扮项：基础色免费，学科主题色与金属质感为会员专属，状态走统一的 `owned / locked / premium / previewing`。
- 佩戴后必须同步到 2D 列表头像与 3D 场景，两处读同一份 `AvatarProfile`，不得各自存一份。

事实边界：
- 学位服的流苏、垂布颜色按学科门类与各校规定执行，产品**只提供可选的配色主题，不宣称"某专业必须是某颜色"**。
- 不出现真实院校校徽、校名作为帽饰；校徽位留空或使用中性图案。

## 6. 电子宠物与成长

成长值来源（全部由 `GrowthService` 统一计算，其他模块只发事件）：

| 事件 | 成长值 | 上限 |
| --- | --- | --- |
| 完成一节课 | 按课程权重 5–20 | 每日封顶 60 |
| 完成一组题 | 按题量与正确率 3–15 | 每日封顶 45 |
| 完成一次模拟面试 | 25 | 每日封顶 50 |
| 每日打卡 | 10 | 每日 1 次 |
| 连续 7 天 | 额外 50 | 每周 1 次 |

等级曲线写在配置里（示例：L1 0、L2 100、L3 260、L4 500、L5 850…），必须可配置且被单元测试覆盖边界值。

宠物状态机：

```
idle ⇄ happy ⇄ studying ⇄ cheering ⇄ sleepy ⇄ reminding
```

- 状态由事件驱动，有最短停留时长，避免高频切换。
- 单个状态动画必须有回退到 `idle` 的路径，不允许卡在一次性动画。
- 成长反馈：升级时播放升级动画 + 解锁内容提示；解锁列表与装扮/场景装饰打通。

## 7. 动画规范

| 状态 | 触发 | 时长 | 可跳过 |
| --- | --- | --- | --- |
| 待机 | 无操作 | 循环 4–8s | — |
| 欢迎 | 进入空间 | 2s | 是 |
| 学习 | 学习任务进行中 | 循环 | — |
| 完成 | 任务完成 | 2.5s | 是 |
| 鼓励 | 伙伴互动 | 2s | 是 |
| 提醒 | 打卡提醒 | 3s，最多 2 次 | 是 |

减少动态效果开启时：一次性动画替换为静态姿态 + 短淡入，循环动画停止，相机不再自动旋转。

## 8. 交互与手势

| 操作 | 手势 | 必须有按钮替代 |
| --- | --- | --- |
| 旋转相机 | 单指拖动 | 是（左/右转） |
| 缩放 | 双指捏合 | 是（+/-） |
| 平移 | 双指拖动 | 是（方向键） |
| 复位 | 双击 | 是（复位按钮） |
| 选中角色/物体 | 单击 | 是（热点列表） |
| 快捷互动 | 长按角色 | 是（互动菜单） |

冲突处理：
- 拖动超过阈值才判定为相机旋转，轻点判定为选中，避免误触。
- 3D 场景内不放必须滑动才能完成的核心学习功能。
- 首次进入给一次手势引导浮层，可跳过，可在设置里重看。

## 9. 资源加载与缓存

```
检查本地缓存（hash + version）→ 命中则直接加载
  → 未命中：异步下载 → 校验哈希 → 解包到缓存目录 → 更新索引
  → 下载失败：用上一版本（如有）→ 都没有则显示占位与重试
```

要求：
- 场景进入前显示进度（百分比或分步文案），超过 2 秒必须出现可感知反馈。
- 大场景分块加载，先加载中心区域，交互热点后置。
- 使用 LOD：远处用低模，近处切高模，切换阈值写在配置。
- 同屏同类物体用实例化（同一模型多次出现只加载一份）。
- 纹理内存上限按档位设置，超限先降纹理分辨率再降模型。
- 缓存有上限与清理策略，清理不影响已拥有装扮配置。

## 10. 性能与系统事件

必须处理：

| 事件 | 处理 |
| --- | --- |
| 切后台 | 暂停渲染与动画，保存状态，回前台按需重建场景 |
| 内存警告 | 释放贴图缓存与非可见场景，降级 LOD |
| 低电量模式 | 自动降帧、停循环动画、降分辨 |
| 设备发热 | 连续高温降帧并提供轻量模式提示 |
| 场景加载失败 | 保留 2D 降级视图，功能入口不消失 |

性能指标（**样板未实测前一律标记待确认**）：目标帧率、首帧时间、场景切换时间、内存峰值、包体增量。先在项目里提出可测量建议值，再在真机记录实测值，两者分开写。

## 11. 学习社区

### 11.1 社交状态

```
online（在线）| studying（学习中）| resting（休息中）| offline（离线）
```

- 状态来源：本地会话活跃 + 服务端 presence。样板阶段用 mock presence，接口按正式设计（订阅房间状态 + 心跳）。
- 状态展示不得暴露精确在线时间，只显示相对描述。

### 11.2 互动

| 互动 | 限制 | 授权 |
| --- | --- | --- |
| 打卡 | 每日 1 次 | 需通知授权才发提醒 |
| 共同学习 | 需对方接受邀请 | 双方可见范围内 |
| 鼓励 | 每日次数上限 | 防骚扰节流 |
| 提醒对方学习 | 每日 1 次/人，可被拉黑 | **必须对方授权且可关闭** |

### 11.3 安全与隐私

- 举报入口在每个可互动对象上，二级选项（骚扰/不当内容/冒充/其他）。
- 拉黑后：互相不可见、不可互动、不在同一房间。
- 昵称与自定义内容需审核态：`pending` 时不对外展示。
- 隐私可见范围三档：仅自己 / 好友 / 公开。默认好友。
- 关闭"允许他人提醒我"后，服务端不得再下发该类消息。

### 11.4 状态同步

| 场景 | 策略 |
| --- | --- |
| 学习完成 | 本地先落库 → 发事件 → 更新宠物与空间 → 异步同步 → 生成社区动态 |
| 离线 | 事件进本地队列，带幂等键，联网后按序补发 |
| 重复事件 | 幂等键去重，重复不重复计成长 |
| 同步失败 | 重试 3 次（指数退避）→ 标记待同步 → 设置页可见"待同步项" |
| 冲突 | 以服务端 `updatedAt` 为准，本地保留冲突快照便于排查 |

为正式实时服务预留接口：

```swift
protocol PresenceProviding { func subscribe(roomID: String) -> AsyncStream<PresenceEvent> }
protocol RoomServicing { func join(_ roomID: String) async throws; func leave(_ roomID: String) async }
protocol CommunityFeedProviding { func fetchFeed(cursor: String?) async throws -> FeedPage }
```

样板提供 mock 实现，真实实现只替换这三个协议，不改视图层。

## 12. 轻量模式

触发条件（任一）：用户手动开启 / 减少动态效果开启 / 低电量模式 / 检测到持续低帧 / 老设备。

轻量模式行为：
- 形象用静态图或低模，宠物只保留 3 个核心动画。
- 停止循环动画与相机自动旋转，环境音关闭。
- 场景仍可进入、仍可点热点、仍可完成所有学习与社交功能。

轻量模式不得导致功能不可用，只降低表现层。
