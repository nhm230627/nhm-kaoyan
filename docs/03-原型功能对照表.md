## 三、六条核心流程（技能要求，必须端到端可走）

| 编号 | 流程 | iOS 里的验收点 |
| --- | --- | --- |
| A | 注册 → 备考档案 → 学习计划 | 计划生成后，今日页出现今日任务入口 |
| B | 刷题或闯关 → 学习结果 → 宠物成长 | 结果页成长值增量 = 伙伴页显示值 |
| C | AI 面试 → 追问 → 反馈 → 错题/课程推荐 | 复盘里的薄弱点可点进题库对应章节 |
| D | 认领 3D 形象 → 进社区 → 伙伴互动 → 学习提醒 | 广场与个人页是同一个形象与状态 |
| E | 会员内容 → 权益判断 → 购买/恢复 | 过期后会员内容立即回到锁定态 |
| F | 刷题闯关 → 通关星级 → 成长值与错题 BOSS | 星级判定正确，错题进 BOSS 关，薄弱点同步 |
